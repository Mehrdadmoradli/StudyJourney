# StudyJourney Data Engine

The StudyJourney Data Engine collects and processes official
study-program data from German universities.

## Responsibilities

- Discover official program sources
- Download HTML/PDF documents
- Extract document content
- Extract structured admission requirements using AI
- Validate extracted requirements and source evidence
- Send validated program data to the StudyJourney backend

## Current scope

Version 0.2 supports downloading online study program sources.
